## Agreed implementation contract

- One restrained spring: `visualDuration: 0.24`, `bounce: 0`.
- Opacity: 0.16s linear. Use literal `transform` strings plus opacity for animation paths; reserve geometry changes for immediate layout updates.
- Reduced motion skips all nonessential entrances, exits, progress motion, and decorative movement.
- Manual Pal selection with factual capabilities replaces autoplay and unsupported metrics.
- Completion feedback is a short status banner; no confetti or infinite attention pulse.
- Generation feedback names the real pending operation. No timer-based percentage or simulated completed substeps.
- Preserve state, data operations, routing, and keyboard access.

## Verification plan

Format and lint the owned files; check TypeScript diagnostics for those files; inspect keyboard, hover/press, reduced-motion, open/close, busy, and completed states during the integrated browser pass. Do not claim a MotionScore or measured performance improvement without a runtime report.
