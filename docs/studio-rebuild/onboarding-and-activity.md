# Studio guidance and task activity

## The member experience

First-time members get a small, dismissible welcome in the page. It offers a four-step checklist: describe the business and audience, add a visual reference, create a first draft, and plan a date. Completion is derived from saved workspace records, not from checking a box. The guide never blocks the page on arrival.

Established workspaces get a different introduction to the refreshed layout. A five-part tour explains Chat and Pal switching; Feed, Ideas, and Campaigns; Library and Calendar; Brand DNA and shared memory; and Usage & billing. It explains that the calendar plans a date without publishing and that the roadmap plans scripts rather than generating footage.

The Guide button, account menu, and navigation menu reopen the guide after dismissal. Welcome preferences are versioned and scoped to both the member and workspace, stored on the current browser. Setup completion itself is shared workspace data. Preferences do not change or delete existing work.

## Real activity, useful personality

A request in progress gets a named Pal, task label, and a short line in that Pal’s voice. Reply, campaign, image, and PDF requests each have a different small animated motif: conversation dots, grouped cards, a framing mark, and layered pages. Supplied 3D Pal scenes give the state a human face. These are motion applied to illustrations, not newly generated animated character videos.

The activity bar is deliberately indeterminate. The current server requests do not stream measured intermediate milestones. It does not invent a percentage, claim a search happened, or mark files saved before the request returns. “What’s happening” explains the context used and the next outcome. Device reduced-motion preferences and the Studio setting remove the loops.

## Scope and activation

These features run locally without paid AI credentials. Live generation quality and latency still require a deployed provider. A true multi-stage completion checklist can be added when server job events expose verified stages; timers should not substitute for those events.
